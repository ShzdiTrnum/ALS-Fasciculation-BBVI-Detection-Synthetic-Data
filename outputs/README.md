# outputs/

Generated plots and arrays are saved here after running the script.

| File | Description |
|------|-------------|
| `rotation_angles_synthetic.png` | Per-ring rotation angle vs. frame index |
| `noise_variance_synthetic.png` | σ_n convergence per pyramid level |
| `mse_synthetic.png` | MSE per pyramid level |
| `elbo_synthetic.png` | ELBO per pyramid level |
| `cor_trajectory_synthetic.png` | COR trajectory with zoomed inset |
| `posterior_variance_synthetic.png` | Per-ring uncertainty over time |

> Output files are excluded from version control via `.gitignore`.
