# data/

Synthetic video and ground truth used for all reported runs (tracked in git; they are synthetic).

| File | Content |
|------|---------|
| `fasciculation_simulation_24frames.mp4` | 980 × 748, 24 frames, 10 textured rings |
| `ring_angles.csv` | 24 rows (frames 1–24) × 10 rings, absolute angle in **degrees**, no header; column 0 = innermost ring |
| `ring_initial_rotation_values.csv` | same values with a `Frame` header column; the first row (frame 1, all zeros) initialises the estimator |
| `ring_center_positions.csv` | `Frame,center_x,center_y`, true rotation centre per frame, image pixels |

Generated by `src/generate_synthetic_video.py`: 980 × 748 px, 5 fps, rings of width 20 px around (490, 374).
Timeline: frames 1–2 rest, 3–9 counter-clockwise (OpenCV positive) rotation to +8°, 10–15 hold,
16–22 clockwise return to 0°, 23–24 rest. Ring speeds run from 5°/frame (inner) to 2°/frame (outer).
During the two rotation phases the centre moves by (+9, +6) px and back, in equal steps.
Each frame also carries a text overlay in the top-left corner and a red dot (radius 6 px) at the centre.

The texture was drawn without a fixed seed, so regenerating gives the same angles and centre path
(verified) but a different texture. Use the files in this folder to reproduce the reported runs.
